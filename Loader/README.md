# 🚀 Loading Animation Challenge

Create a smooth, lightweight loading animation using CSS.

## 🎯 Challenge

- Build a loading animation (spinner, progress bar, or custom design) with CSS keyframes and transforms.

## 🛠 Tech Stack

- HTML
- CSS (Animations & Transforms)
- Vanilla JavaScript (optional)

## ✅ Requirements

- Smooth CSS animation.
- Optional fade-out after load.
- Responsive and browser-compatible.
