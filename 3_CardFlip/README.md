# 🎴 Card Flip Interaction Challenge

Create an interactive card flip effect using CSS.

## 🎯 Challenge

- Design a card that flips on hover or click using **CSS 3D transforms**.
- Animate both the front and back of the card smoothly.
- Bonus: Allow the flip to trigger on click using minimal JavaScript.

## 🛠 Tech Stack

- HTML
- CSS(3D Transforms & Transitions)
- Vanilla JavaScript (optional for click interaction)

## ✅ Requirements

- Smooth and responsive 3D card flip.
- Works across different screen sizes and browsers.
- Optional click-to-flip using JS.
